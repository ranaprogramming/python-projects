# Python Projects Collection

A collection of Python projects developed to practice and demonstrate fundamental and intermediate Python programming concepts, including object-oriented programming, data management, file handling, JSON, user input, business logic, and basic machine-learning dataset management.

## How to Run

Make sure Python is installed on your computer.

Check the Python version:

```bash
python --version
```

Run an individual project:

```bash
python filename.py
```

Examples:

```bash
python Banking.py
```

```bash
python todo.py
```

For files containing spaces in their names:

```bash
python "E-Commerce Backend Simulation.py"
```
